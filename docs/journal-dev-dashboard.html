Module

Der Client liest und schreibt lokal. Firestore-Writes laufen über track() und werden nicht awaited. Routing ist der URL-Hash (src/lib/hashRoute.js, src/lib/useHashRoute.js). Tabs registriert src/routes.js.

Hosting

Projekt fitness-aos. Inhalt ist Target v2 (dist-v2). Solo-PWAs baut scripts/build-journal-minis.mjs nach dist-v2/mini/. Befehl: pnpm run deploy:v2:build.

Stolperstellen

  • Hash ist die einzige Quelle für Tab, Modus und Datum. navigate liest den Hash im selben Tick erneut, zwei Aufrufe überschreiben sich nicht.
  • #v2/suche bleibt nicht stehen. Die Modusleiste schreibt den Hash, der Parser setzt tag.
  • Jahr ist #v2/jahr. Ein Klick auf einen Tag setzt den Modus auf tag, der Monatskopf auf monat.
  • v2 importiert Journal-CRUD aus src/lib/db/journal.js, nicht über @journal-db.
  • Entwürfe: Tastendruck nach localStorage, Speichern entprellt (draftStore.js, useAutosaveField.js). Blur allein ist nicht der Speicherzeitpunkt.
  • Lokal ist node_modules oft ein Symlink auf den vitalos-Workspace. Builds, die pnpm run einen Install-Check auslösen lassen, können daran hängen. CI installiert mit --frozen-lockfile; package.json und Lock gehören in denselben Commit.
  • Vite 8 / Rolldown: fixRolldownPreloadMarker und scripts/fix-vite-preload-markers.mjs bleiben. Ohne sie bleibt ein Hash an __VITE_PRELOAD__ und das Bundle ist kein gültiges JavaScript.
